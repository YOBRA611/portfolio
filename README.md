## 📦 System Architecture & Features

This portfolio is packed with performance-focused features and clean layout logic:

*   **Dual-Action Project Matrix:** 12 live web application components outfitted with parallel `View Live Production` and `View Source Code` execution buttons.
*   **Asynchronous UX Enhancements:** Integration of the Scroll Animation (AOS) engine utilizing calculated data-delays for polished, non-blocking interface entry transitions.
*   **Strategic Conversion Funnels:** A custom, fully-validated direct lead intake form connected to a backend ingestion API (`Formspree`), alongside a programmatic floating WhatsApp action script for rapid contract negotiation.
*   **Performance Optimization:** Strategic implementation of native browser asset lazy-loading for heavy graphical layout galleries.
